# Genra outcome checklist

- [ ] **Foundation and design system:** The app uses a black full-bleed canvas, Instrument Serif display typography with italic accent words, Kanit UI typography, liquid-glass cards and pills, teal verification signals, the specified CTA gradient, responsive mobile-first layouts, visible focus rings, and reduced-motion fallbacks.
- [ ] **Marketplace navigation and role switch:** A persistent rounded navbar includes the Genra mark, Creators, Post a Brief, How it works, a Brand/Creator role switch persisted in localStorage, and a Sign up CTA.
- [ ] **Landing experience:** The landing route has a cinematic hero with the headline “Hire the AI-native creators.”, search affordance, primary CTAs, hero object treatment, marquee work rails, a Why Genra section, three-step workflow, featured creator cards, verification story, final CTA, and footer.
- [ ] **Creator discovery:** The creators route supports query search, sort, filter chips, tool/specialization/format/commercial-use/verification/availability filters, live result counts, removable filters, loading and empty states, and shareable URL query state.
- [ ] **Creator profiles:** A creator detail route shows profile identity, verification score, availability, rating, price, portfolio items, tools/models, workflow steps, licensing, formats, and an invite action.
- [ ] **Brief creation and management:** The brief builder accepts a rough idea, extracts structured fields, presents editable campaign/content/requirements/commercial-use/budget sections, shows completeness, and creates a brief; list and detail views show statuses and match rails.
- [ ] **Transparent matching:** Brief matches rank creators with visible tool, skill, format, commercial-use, and verification factors, plus invite interactions.
- [ ] **Creator workspace:** Creator role dashboard supports profile editing cues, portfolio/tool management cues, verification requests, and invitations.
- [ ] **Backend and data docs:** Express JSON endpoints exist for creators, profiles, briefs, matches, invites, and brief-builder; seed data is deterministic and the data model and demo script are documented.
- [ ] **Quality and delivery:** The app builds cleanly, route manifest is served, preview listens on port 3000, and the project is checkpoint-ready.
